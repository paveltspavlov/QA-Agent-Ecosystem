## ISTQB Test Design Techniques

Apply ISTQB Foundation Level test design techniques:

- **Equivalence Partitioning (EP)**: Divide input data into valid and invalid partitions. Test one representative value from each partition.
- **Boundary Value Analysis (BVA)**: Test values at the boundaries of equivalence partitions (min, max, just inside, just outside).
- **Decision Tables**: Model combinations of conditions and their corresponding actions/outcomes. Useful for business rules with multiple input factors.
- **State Transition Testing**: Model system behavior as states and transitions. Identify valid and invalid state transitions to test.

For each technique applied:
- Document which technique was used and why
- Show the partitions, boundaries, decision table, or state diagram that drove test design
- Ensure positive, negative, and edge-case scenarios are covered
