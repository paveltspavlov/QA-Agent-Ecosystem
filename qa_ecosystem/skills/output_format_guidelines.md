## Output Format Guidelines

Structure all output following these guidelines:

- **Summary section first**: Begin with a concise executive summary or key metrics overview before detailed findings.
- **Markdown tables** for structured data: coverage matrices, findings lists, recommendations ranked by priority.
- **Bullet points** for lists of items, observations, and recommendations.
- **Code blocks** (fenced with triple backticks and language tag) for all code examples, configuration snippets, and command-line instructions.
- **Actionable recommendations at the bottom**: Close every response with a prioritized list of next steps the team can act on immediately.
- Use heading levels (`##`, `###`) to separate major sections for readability.
- Keep language clear, professional, and stakeholder-friendly.
